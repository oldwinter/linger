# Rooms and Messaging

Rooms and Messaging covers creating group Rooms, enrolling members, posting and reloading `@`-mentioned messages, observing local Agent run status, pinning and unpinning Room messages, inspecting Room details, and sharing or revoking read-only conversation snapshots.

## Sub-features

- Creating a multi-member Room (`Create chat` -> `Create Room`) and enrolling existing members (`Add Room members` -> `Choose existing members`)
- Posting messages in `Room timeline` and verifying reload persistence (`article[data-message-id]`)
- Triggering local agent runs (`@<Agent>` mention or messaging `Another Me`'s Room) and observing `[data-testid="agent-streaming-status-dock"]`
- Fork-only Message Pins (`More message actions` -> `Pin message` / `Unpin message`, header `Pinned messages` button + `[data-testid="pinned-messages-count"]`, `dialog "Pinned messages"` with `Search pinned messages`, `Copy pins`, `Go to message`, `Unpin`, and `Close pinned messages`)
- Managing Room metadata (`Open <Room> details`), navigation actions (`More actions for <Room>`), and read-only conversation link sharing with two-step revocation (`/shared-room-history#room_share_...`)

## How to get to it (user POV)

- From the workspace sidebar (`Room navigation`), click `Create chat`, choose `Create Room`, name the Room, and immediately land on `/t/:tenantId/rooms/:roomId/chat` with `Add Room members` overlaid to add members or skip.
- Inside a Room, compose in `Message Room`, inspect replies in `Room timeline`, hover or focus a message row to open `More message actions` (including `Pin message`), open header `Pinned messages` to browse/jump/unpin Room pins, toggle `Show sidebar` (`Panel sidebar`) for linked `Files` and details, or open `Open <Room> details` and the header `More actions for <Room>` menu.

## Gotchas

- `Add Room members` -> `Choose existing members` opens a non-modal `dialog "Choose members"` inside `region "Members"`; wait on `--text "Research Analyst"` and click the `@e` ref for `button "Research Analyst avatar Research Analyst"` inside `region "Agent"` because `find role button --name "Research Analyst"` substring-matches background sidebar buttons (`Pin Research Analyst`, `More actions for Research Analyst`).
- Target the Room composer with `[aria-label="Message Room"]` rather than `find role textbox --name "Message Room"`. Multi-member Rooms require selecting an actor from `listbox "Mention people or documents"` after typing `@...` so `mentioned_actor_ids` and `agent_local_runs` are populated.
- Default `up` mode runs `codex-app-server-fixture`, which ends its turn with `"fixture complete"` without calling `teamhub message send` into the Room timeline. `room-reply-guard` + `RunLoop` therefore mark the Room run `status = 'failed'` with `terminal.failure.code = 'reply_not_sent'`, and the UI dock renders `Couldn't finish. It finished without replying. Ask again.` (without a `Run failed: Codex:` prefix). Start `up --live-provider` whenever verifying live agent message posts back into chat.
- `.message-row-actions` (containing `More message actions` and `Pin message`) stays `opacity: 0; pointer-events: none` until the message `article[data-message-id]` is hovered or focused; call `hover 'article[data-message-id]'` first. Message Pins are also not pushed over `/v0/events` SSE, so cross-tab checks require a reload or query refetch.
- Do not use unscoped `find role button --name "Close" click` to dismiss `Share conversation` while Room details is open: it substring-matches `Close <Room> details` behind the modal. Pass `--exact`, click the modal's `@e` ref from `snapshot -i`, or press `Escape`.
- `More actions for <Room>` renders in both `Room navigation` (sidebar row) and inside `region "Room <Room>"` (Room header); only the header menu includes `Hand off`, `Add a document`, `How work moves`, `Who can manage`, `Routines`, and `Step out`. Target `section[aria-label="Room <Room>"] button[aria-label="More actions for <Room>"]` or the header `@e` ref.
- Click-opened `ActionMenu` popovers suppress outside-dismissal click-through onto underlying controls; press `Escape` or click twice if dismissing an open menu before clicking another target.
- At `1280x600` or `1280x720`, `Share conversation` in the Room settings panel (below `Room members` and `Routines`) and `Revoke` / `Confirm revoke` inside `Share conversation` can sit below the fold; call `scrollintoview` before clicking them. `RoomDeleteDialog` confirms directly with `Delete Room` (no Room-name retyping field).
